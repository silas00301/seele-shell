Inspect JWT in Text workbench decodes one compact JWT locally. Its header and claims are shown as JSON with original number lexemes and duplicate keys preserved. The signature is not verified, and neither issuer, audience nor expiry is checked. No key retrieval or network request occurs. Even a token with an empty signature can be inspected; decoded claims are untrusted data, never authorization. Input stays in the open panel and its editor undo stack is destroyed on close. Copying is explicit and carries the warning with the result. The existing 64 KiB / 256 KiB limits apply.
