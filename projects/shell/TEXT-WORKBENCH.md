Text workbench keeps input and results only while its panel is open. CSV → Markdown takes the first comma-separated row as a header. Double-quoted fields support commas, line breaks and doubled quotes. Every row must have the same width, up to 1,000 rows and 64 columns, within the existing 64 KiB input / 256 KiB output limits. Malformed input produces no partial output. Cells escape HTML and Markdown delimiters; embedded line breaks become `<br>`. Preview before explicitly copying. Existing Alt-number choices remain unchanged; Tab reaches the CSV choice.
